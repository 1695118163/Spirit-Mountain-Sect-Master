# 灵山掌门

水墨风修仙放置挂机网页游戏 + 本地 LLM 动态奇遇。零第三方依赖，全程免费可玩。

## 启动（两种方式）

### 方式一（推荐，功能完整：含 LLM 动态奇遇）

1. 双击游戏文件夹里的 `start.bat`，会弹出一个黑色命令行窗口——这是本地代理，**玩游戏期间不要关它**（关了 LLM 奇遇就没了，但游戏照常能玩）。
2. 浏览器会自动打开游戏页；没自动开就手动在浏览器地址栏输入 `http://127.0.0.1:8787`，可以收藏这个地址。
3. 下次再玩：还是双击 `start.bat` 即可，进度自动接着上次的来。

### 方式二（纯单机模式）

- 直接双击 `index.html` 就能玩。建造、突破、内置奇遇、转生全部可用；只有"LLM 动态奇遇"不可用（状态灯是红色），想用就改用方式一。
- 若双击 `start.bat` 一闪就退，多半是电脑没装 Node：去 nodejs.org 下载安装 LTS 版（免费），装完再双击一次。

## 填 API Key（开启 LLM 动态奇遇，免费额度内）

前提：本机已装 arkcli 并完成过火山账号登录。照抄以下步骤（在 PowerShell 或 CMD 里逐行执行）：

1. `arkcli auth status` —— 确认已登录（本机已 SSO 登录过，一般不用再做）。
2. `arkcli resources list` —— 在输出里确认有你要用的模型（当前配置 `glm-5-2-260617`）。
3. `arkcli auth apikey` —— 按交互提示获取/确认 API Key，复制整串。
4. 粘贴密钥，二选一：
   - 打开游戏 → 设置页 → 密钥输入框粘贴 → 保存（会写入 config.json）；
   - 或用记事本打开游戏文件夹里的 `config.json`，把 Key 粘到 `ark_api_key` 的引号里，保存后重启 start.bat。
5. 刷新页面，状态灯变绿即成功。
6. 想看还剩多少免费额度：`arkcli usage balance --type free-quota`。

> 模型说明：当前 config.json 预填 `glm-5-2-260617`（GLM-5.2，账号下有 FreeInference 免费额度资源包）。
> 原方案里的 `glm-5-3-flash` 属于 AgentPlan 套餐（已过期不可用），如续订套餐可改回。
> 配置了 `thinking: disabled`（奇遇短文案不需要思考链，响应更快）。

## 导出 / 导入存档

- 游戏内：设置页 → 存档 → 「导出」生成文本，复制保存到记事本；「导入」把文本粘回输入框确认即可恢复（导入前当前进度会自动备份，不怕手滑）。
- 换浏览器 / 换电脑：先导出，到新环境导入。
- 手动救急（进阶）：存档在浏览器本地，按 F12 → Application → Local Storage → 找到 `lingshan_save_v1` 键，可复制/粘贴整串文本。
- 转生时会自动下载一份本世完整存档（`lingshan_backup_时间.json`）留档。

## 额度用完了怎么办

- 现象：状态灯变黄或红，提示"免费额度已用尽"。
- 影响：仅"LLM 动态奇遇"改为由内置事件池出题，建造、突破、离线、转生等一切玩法照常，**游戏全程免费、绝不自动产生任何费用**。
- 处理：什么都不用做，等免费额度刷新后状态灯自动转绿；想确认额度随时执行 `arkcli usage balance --type free-quota`。本游戏不内置任何付费通道。

## 玩法速览

- **吐纳**：点中央大圆钮（可按住连点），得灵气与修为。
- **突破**：修为攒满 → 金色「突破」按钮亮起 → 点击破境（练气→筑基→…→飞升，共 10 境）。
  - **突破有失败率**：练气、筑基必成；金丹起越往后越难（金丹 95% → 飞升前 60%），道心高有加成、道心低有惩罚。
  - **失败后果**：修为保留一半、按钮冷却 30 秒调息；失败时还可能**走火入魔**（境界越高越容易）——修为再折损一半 + 全局产量减半的负面状态（120~300 秒）。
  - **连败保底**：连败 3 次后下一次必定成功，不会卡死。
- **停滞彩蛋**：卡在同一境界太久（练气约 8 分钟起，境界越高越久）会触发**顿悟**（白得一大截修为 + 点击增益）或**心魔**（扣修为 + 产量减益）；练气、筑基期只出顿悟不出心魔。
- **奇遇排队**：同一时间只弹一张奇遇卡；没处理完时来的新见闻自动排队（最多存 3 条，超出丢最旧），处理完当前卡后自动弹出下一条。打开设置/转生面板时奇遇也会乖乖排队，不会顶掉你的面板。
- **建筑**：左栏 12 种洞天福地随境界解锁，自动产出。
- **奇遇**：约每 4 分钟三选一上门（离线不触发），「离去」永远安全；旧事件会种下因果，日后有人来报恩或讨债。
- **转生**：修至化神解锁「兵解转世」，传承点兑换永久加成，来世重修更快。
- **调试**：URL 加 `?dev=1` 获得 `window.__lingshan` 钩子（跳时间/加资源/强制事件/千抽统计）。

## 开发者

- `node balance_check.js` —— 数值平衡模拟门禁（双画像 + 验收阈值，退出码 0/1）。
- `node tools/validate-events.js --stats` —— 事件池校验（61 条首发，含禁数字/结构/池规则）。
- 数值全部在 `data/balance.json`，事件在 `data/events.json`；改数值不用动代码。
- 里程碑：`v0.1.0-m1` 骨架 → `v0.2.0-m2` 全建筑+离线 → `v0.3.0-m3` 事件池 → `v0.4.0-m4` LLM → `v0.5.0-m5` 水墨+转生。
