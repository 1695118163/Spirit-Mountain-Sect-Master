# 《灵山掌门》好友斗法扩展方案 v1（2026-09-06，仅方案待拍板）

来源：玩家反馈「化神后没内容」「加好友+好友对战」「丹药武器功法属性克制」「境界碾压论」「QTE」「电子拔河」「境界差距越大越困难」。

## 0. 一句话总览

**「斗法」= 多轮 QTE 电子拔河**：与好友（或其影子）五至七轮攻防拉锯，境界修为是底盘、丹药是临场 buff、武器定杀伤、功法五行定克制——操作好可以以弱胜强，但境界碾压超过三层神仙难救。

## 1. 好友系统：好友码 + 影子制（关键决策一）

纯前端+localStorage 没有账号体系，好友联机用**名片码**方案（与现有存档导出/导入交互同构，零后端依赖）：

- 每位掌门有一张**道号名片**（可复制的一串码）：道号、境界、道心、战力评份、武器/功法/丹药构筑摘要、胜负战绩；
- 「添加好友」= 粘贴对方名片码 → 存入好友列表（localStorage，跨转生保留）；
- **斗法打的是对方的「影子」**：系统用对方名片里的构筑快照生成一个 AI 对手（对方当时的境界、武器、功法、属性），**不需要对方在线**，甚至不需要对方知道——发完码就能被好友偷偷挑战；
- 战绩写进双方可见的名片（下次对方更新名片码发过来就能看到「被你 3:1 打哭」）。

> 为什么不做实时联机：实时对战需要 WebSocket/后端房间，工程量和服务器压力翻几倍，且「异步影子斗法」是放置游戏社区的经典成熟形态（Crazy Joe、Idlelon 均如此）。后续公网版可以加「云端擂台榜」（Phase 2）补社交闭环。

## 2. 斗法本体：多轮 QTE 电子拔河

**一条灵机拔河条**（全屏横卷）：中央指针开局，双方把指针往对方端点拉。**5~7 轮**，每轮一个 QTE，轮末按表现差移动指针；指针被拉到己方端点即落败（提前结束），轮数打满按指针位置判定。

**四类 QTE（全部鼠标可完成）**：

| 类型 | 玩法 | 对应能力 |
|---|---|---|
| 连点 | 3 秒内连点吐纳符，次数定输出 | 基础修为（点击党友好） |
| 缩圈 | 收缩圆环与目标环重合瞬间点击，连续 3 次 | 时机把控（时机型） |
| 蓄力 | 按住蓄力条，在金色区间内松手 | 力度拿捏（蓄力型） |
| 符序 | 依序点亮随机出现的五行符文 | 反应与记忆 |

**影子 AI 的表现** = 对方构筑数值 × 随机波动；**QTE 难度随境界差动态调整**（核心规则，按玩家要求）：

- 境界差 ≤1 层：QTE 标准难度，势均力敌，操作定胜负；
- 境界差 2 层：影子拉力 +30%，QTE 窗口缩小 20%——弱势方要靠丹药/武器/克制翻盘；
- 境界差 ≥3 层：碾压系数陡增（影子拉力 ×3 起），QTE 窗口缩半——**碾压了很多就是有用**，勉强搏一手「逆转天命」（极小概率暴击轮）；
- 反过来，**低境界挑战高境界**：赢了收益翻倍（以下克上，战绩碑林记一笔）。

## 3. 丹药、武器、功法：三线养成 + 五行克制（关键决策二）

境界不再是唯一答案，三条养成线各自喂给斗法不同的维度：

**武器（锋锐——决定 QTE 输出伤害）**
- 品阶凡/灵/珍/仙；每件有锋锐值 + 五行属性；奇遇掉落、坊市购买、**炼器**（新：炼丹炉姊妹玩法，用灵气+矿石炼器）三条获取途径；
- 可升阶（同名武器 +1，锋锐叠加）。

**功法（五行——决定克制关系）**
- 一部主修功法槽，五行：金木水火土；**克制环：金→木→土→水→火→金**（克对方功法：拉力 +25%；被克：−15%）；
- 功法自带 QTE 特效（如火灵功：连点轮每点额外火星伤害；水灵功：缩圈轮时间放缓 10%）；
- 获取：奇遇（高境界池）、坊市稀有货、斗法段位奖励。

**丹药（临场——斗法前的战术准备）**
- 复用现有丹药系统：斗法前可服斗法专属组合（灵力丹拉力、破障丹 QTE 容错、清心丹免疫心魔干扰——对方影子可能在斗法中对你用心魔）；
- 斗法内不嗑药（公平），嗑药在战前准备阶段。

**境界（底盘——决定基础拉力与碾压）**
- 每层境界差 = 拉力 +20% 复利（见 §2）；修为总量的 10% 折算成「道基厚度」附加拉力。

## 4. 结算与成长

- **胜**：论道积分 +（对方境界越高越多）、战绩 +1、低打高额外碑林记事、概率触发对方「不服」事件（下次影子变强 20%——复仇局）；
- **负**：道心 −3（胜 +2）、战绩记录、无资源损失（斗法切磋，不伤根本）；
- 段位：凡品 → 灵品 → 珍品 → 仙品（按积分），段位解锁更强的「天骄影子」（系统生成的强 AI 榜样，打它校准构筑）。

## 5. 内容填补（解决「化神后没东西」）

化神 → 飞升的空窗期由斗法承接：这个区间正是**武器功法成型、五行配队（选择克制好友功法的构筑）、段位冲分**的主战场。配合数值组的四档 debuff/丹毒系统，化神后每一层都有新的斗法环境要适应。

## 6. 与现有系统的咬合

- **道心**：斗法胜负小幅影响道心；道心高 QTE 容错 +（复用现有道心收益链）；
- **碑林**：以下克上、段位晋升自动刻碑；
- **指要**：新增「斗法与好友」节；
- **名片码**：与存档导出共用 UI 模式，学习成本为零。

## 7. 实施分期

| 期 | 内容 | 工作量 |
|---|---|---|
| Phase 1（核心可玩） | 武器+功法+五行克制系统、QTE 拔河斗法（4 类 QTE）、好友码名片、影子 AI | 10~12h |
| Phase 2 | 公网云端擂台榜（Python 端点：名片上传/榜单/热门对手） | 4~6h |

## 8. 需要拍板的三个决策

1. **影子制 vs 实时联机**：建议影子制起步（零后端压力、离线可玩、异步社交），云端榜 Phase 2 再补——同意？
2. **武器功法获取倾向**：奇遇掉落（惊喜感）/坊市购买（肝度可控）/炼器（新玩法）——建议三者都有但奇遇为主，比例待定；
3. **碾压保护尺度**：境界差 ≥3 层是否允许极小概率逆转（玩家要求「差距越大越困难」但没说绝对不可能）——建议允许 2% 的「天命逆转」暴击轮，纯爽点。
