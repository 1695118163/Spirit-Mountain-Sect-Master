# 《灵山掌门》下一版玩法扩展提案（策划 agent 出品，2026-09-05，仅方案未实施）

十个提案，全部围绕「让已有的叙事资产动起来」展开，不拉养成线、不加付费点、新内容尽量进 JSON。

---

## 一、叩山 · 故人上门（因果兑现）

1. **概念**：因果台账不再只是图鉴里的一行灰字——有恩怨未了的故人会在关键时刻亲身登门：突破出关当口有人求见（恩人护法加成 / 仇人搅局降成功率）、离线归来有人候在山门外，当面讨债或报恩。
2. **为什么好玩**：让几小时前的选择真正「疼」或「暖」，恩怨从记录变成对峙，直击重视选择后果的叙事型玩家。
3. **实现要点**：events.json 新增 visitor 类事件，带触发时机字段（pre_breakthrough / offline_return）与 karma_id 关联；主逻辑在突破流程前插入「山门外有人求见」中断弹窗，结算结果写回道心与资源；台账 UI 加「在途」状态。
4. **工作量**：4~5 小时
5. **风险/克制**：每局限 1~2 次上门，怨债可选拒不见客（有代价），避免变成惩罚轰炸打断挂机节奏。

## 二、宿慧 · 三世缘（跨转生重逢）

1. **概念**：转生不清空因果——上一世结缘的故人这一世以转世之身再入奇遇池，文案按「初见 / 似曾相识 / 重逢」三档递进，图鉴新增「隔世」标记，凑齐三世缘成一条隐性收集长线。
2. **为什么好玩**：给一局一小时的转生循环装上跨世叙事脊柱——重开不是重刷数值，是「这一世换种活法再遇见你」。
3. **实现要点**：localStorage 永久区加跨转生 karma_legacy 数组；events.json 事件加 requires_past_flag 条件字段与三档文案模板；图鉴加「三世缘」分栏。
4. **工作量**：4 小时
5. **风险/克制**：跨世文案以内置模板为主、LLM 只做可选润色，降级路径必须无损。

## 三、《山志》 · 掌门手札与飞升刻碑

1. **概念**：系统把这一世大事（突破、奇遇、故人、顿悟）自动写成编年体《山志》，飞升或兵解时凝成一篇碑文，刻入跨转生保留的「碑林」，可一键复制成纯文本分享。
2. **为什么好玩**：一局一小时终于有墓志铭，白纸黑字看见自己这世活成了什么样。
3. **实现要点**：基于现有事件日志加 chronicle 模板缓冲；飞升结算时按规则抽 8~12 句拼碑文存入 localStorage 碑林；图鉴加碑林页签。
4. **工作量**：3~4 小时
5. **风险/克制**：模板句式必须一次写足水墨味，宁少记，只记大事。

## 四、判词 · 身后道号

1. **概念**：转生结算时，天道按这一世道心区间、因果清算与标志性事件给出四六骈句「判词」，并授一枚永久道号（如「斩情真君」「守拙散人」）佩于掌门名帖，纯荣誉零加成。
2. **为什么好玩**：把「这局我是谁」变成可佩戴的身份与名号收集。
3. **实现要点**：判词模板按道心区间×标志事件标签选行，放 judgments.json；道号存永久区，名帖展示历世判词。
4. **工作量**：3 小时
5. **风险/克制**：道号必须纯荣誉，一旦给数值加成就破坏约束。

## 五、观天 · 灵潮与节气

1. **概念**：双时间系统长出「天气」——游戏纪年每旬轮转天时（灵潮 / 月圆 / 大雾锁山 / 天狗食日），分别调整产出、奇遇池权重或开启限时事件窗口。
2. **为什么好玩**：挂机从「放着自己长」变成「看时辰下锅」。
3. **实现要点**：balance.json 加天时表，主逻辑按游戏纪年换算轮转；顶栏加一枚程序化 SVG 天时签。
4. **工作量**：4 小时
5. **风险/克制**：加成控制在 ±30% 内，偏好改池子构成而非堆产出。

## 六、拾方 · 丹方残卷

1. **概念**：奇遇掉落残缺丹方（跨转生收集品），集齐后炼出限次强效丹——如渡厄丹：下次突破必成，但道心 −2，用完即逝。
2. **为什么好玩**：把「捡碎片」和「开炉赌一把」缝成闭环。
3. **实现要点**：balance.json 加 recipes 数组；丹方作为图鉴条目；炼丹炉技能加投方分支。
4. **工作量**：4 小时
5. **风险/克制**：「必成丹」会拆掉突破失败率的戏剧性——限定高境界不可用或代价极重。

## 七、立规 · 宗门三章

1. **概念**：每世开宗时从戒律库选三条立为门规，门规改变道心漂移方向、解锁专属奇遇，违戒时触发「执法弟子请罪」抉择。
2. **为什么好玩**：一局之内玩出宗门人格，复玩动机来自「换个活法」。
3. **实现要点**：events.json 加 precepts 库与事件绑定字段；道心结算读门规修正；开局流程加三选页。首发戒律不少于 8 条。
4. **工作量**：4~5 小时
5. **风险/克制**：每条门规都得是「束缚换独有收益」，戒律池薄了就没得选。

## 八、问津 · 秘境小径

1. **概念**：坊市偶售残破舆图，掌门亲入一处 3~4 节点的文字秘境（复用三选一弹窗），每步押上时间与资源、遇宝遇险，每局限入一次。
2. **为什么好玩**：把「赌突破概率」的手感扩展成一段可控的赌途。
3. **实现要点**：新增 expedition.json 节点图（与 chains.json 同族），复用奇遇弹窗；入口挂坊市技能分支。
4. **工作量**：4 小时
5. **风险/克制**：奖励限次 + 走消耗品与图鉴，不走永久数值。

## 九、托梦 · 山中无岁月

1. **概念**：离线归来按离线时长档位与在途因果生成一段「弟子来报，山中这几日……」的梦中叙话，附一个小抉择。
2. **为什么好玩**：给挂机回流瞬间一个「翻牌子」式的期待。
3. **实现要点**：离线结算处挂 offline_event 钩子，模板池按时长档筛选；不改收益数值。
4. **工作量**：2~3 小时
5. **风险/克制**：仅长离线（>2 小时）触发且模板池要厚。

## 十、歧路 · 五仙归途

1. **概念**：飞升按道心、因果、门规分出五条仙路（兵解转世 / 尸解留形 / 携山飞升 / 斩三尸 / 红尘仙），各有收束文案，跨世集齐五图。
2. **为什么好玩**：终局变成照出这一世活法的分岔之镜。
3. **实现要点**：新增 endings.json（条件互斥+优先级链），飞升结算改判结局；图鉴加「仙路」五格。
4. **工作量**：4 小时
5. **风险/克制**：五结局条件必须互斥清晰、玩家可读懂可追。

# TOP3 推荐

**① 叩山 · 故人上门**（4~5h）——性价比之王。因果台账是本作最有辨识度的系统，但目前「只记账不动账」；把它在突破这个最高压力时刻点燃，零新增概念就把戏剧性翻倍。

**② 宿慧 · 三世缘**（4h）——结构性价值最高。转生纯数值重置缺跨世叙事脊柱；三世缘直接回答「我为什么要开下一局」。与图鉴跨转生保留机制天然同构。

**③ 《山志》与飞升刻碑**（3~4h）——复利型基础设施。单独成立（每局的情感出口+分享物），又是判词、五仙结局的公共底座。

**顺手先做**：只想花一个下午，先上「托梦」（2~3h），改动面最小、触发频次最高。

**化学反应**：①+②补全因果「现世讨债、隔世续缘」闭环，③给每局一个「正史容器」。
