# 《灵山掌门》丹药体系方案 v1 定稿（辅助窗口设计，2026-09-05，含用户两轮反馈，未实施）

## 设计三原则（源自修仙小说套路 + 用户裁定）

1. **丹分品类**：不同丹管不同事（常备/冲关/疗心/排毒/固本/破境）；
2. **丹分五阶：劣 < 凡 < 灵 < 珍 < 仙**——品阶越高好处越纯，越低副作用越重（劣品是黑心坑）；
3. **丹毒=体质**：吃带副作用的丹积丹毒（0~100），体质越差药效越打折；丹毒随游戏时间自然消退（随时间消失的），清心丹加速排（吃药治的），转生清空（靠转生清的），「丹瘾」类种因转生也带过去（带记忆和技能，转生也不行）。

## 丹毒数字规则（初步）

- 丹毒 0~100；每 10 点全局产量 −3%；
- 随游戏时间每天自然排 2 点；清心丹一次排 10 点；洗髓丹清零；转生清空；
- **丹毒 ≥ 50：所有丹的增益效果减半**（体质差吃什么药都打折）；
- 「丹瘾」种因：不可排、转生不清，在碑林记一世「以身证道」后化解。

## 获取途径

- 炼丹炉常产**聚灵丹**；「开炉」技能随机出聚灵/凝气（小概率出**劣品**——火候失手）；
- 奇遇丹药奖励改为指定丹种（按稀有度+池子映射：白狐送清心丹、货郎卖"破障丹"实为假货等）；
- 坊市「赶集」带货：灵石可买低阶丹，偶尔混入**来路不明的劣品**（便宜、描述含糊——买不买看玩家眼力）；
- 丹方残卷（关联"拾方"提案）：集齐解锁高阶丹的炼取。

## UI

- 顶栏「服丹」→「丹囊」面板：每种丹库存/药效/丹毒警告一目了然；
- 道心旁加**丹毒条**（体质可视化）；
- 劣品丹详情注明「来路不明」；天元破境丹在高境界时描述自动变为「大幅提升成功率（天道面前，丹力有穷）」。
