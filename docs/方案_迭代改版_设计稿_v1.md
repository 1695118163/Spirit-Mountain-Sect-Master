## 一、截图问题确认

1. 截图一：手机竖屏下 body 背景是**纯色灰蓝**（`--paper` 单色），顶部状态卡下方空白区、主面板左右两侧全部裸露——丑、不仙。
2. 截图二：长按「吐纳」圆钮出现**浅蓝色大色块** = 移动端浏览器默认触摸高亮（tap-highlight）+ 长按选中，全局无抑制样式。

## 二、背景美化方案（纯 CSS，零图片资源）

- body 底层：宣纸底色 → 三层叠加
  - **远山剪影**：两道 `linear-gradient` + `radial-gradient` 组合的黛青色山峦（上淡下浓，贴左右两侧与底部），透明度 0.12~0.2，不抢正文；
  - **云雾带**：两条横向白色→透明渐变雾带（高 18%/26% 处），叠 0.08 透明度，配合现有 ambient 云雾动画层呼吸漂移；
  - **纸纹**：`repeating-linear-gradient` 45° 细丝纹（间距 3px，透明度 0.03）+ 一个 64px 的 radial 晕点纹理，模拟宣纸纤维。
- 顶部状态卡：底色改半透明玉白（rgba 米白 0.92）+ 1px 黛青描边 + 轻投影，与背景层次分明；主面板同款微调。
- 夜色主题（html.night）：远山改墨黑剪影、云雾改月白、纸纹保留——同套结构换变量，不做第二份代码。
- 验收：正文对比度不降（正文区仍是实底卡片），截图位置（两侧/顶部）全部有内容不再裸露。

## 七、传承系统（掌门亲传——数值设计稿，**待确认**）

### 7.1 流程
1. **收徒**：主线第一章完成 → 弹剧情收首位亲传弟子；弟子面板显示境界（自动缓慢成长：每现实分钟 +0.4% 掌门境界进度，可用丹药「投喂」加速——消耗丹药按品质折算成长值）。
2. **太上长老**：掌门突破**化神** → 自动剧情「传位大典」，亲传弟子升**代理掌门**（成长速度 ×2）。
3. **转正**：代理掌门修到**化神大圆满** → 弹「代际传承」四选一（玩家拍板结局）→ 结算：本世传承点照常入账 + 结局加成 → 新一代掌门开局（=一次转生，保留传承点/天赋/图鉴）。
4. 亲传弟子可再收徒（最多同时 1 位亲传，形成单线代际链）。

### 7.2 四种结局加成（下一代 = 新掌门开局）

| 结局 | 剧情一句话 | 下一代加成 |
|---|---|---|
| 继续当掌门 | 「灵山不可一日无主。」 | 初始灵气 +20%，传承点 +10% |
| 成为太上长老 | 「垂帘听政，扶一代又一代。」 | 修炼速度 +8%，初始灵根抽到真/异概率 +15% |
| 云游四海 | 「天地为庐，处处是山门。」 | 奇遇频率 −10%、仙品权重 +2，传承点 +15% |
| 闭关不出 | 「一闭关，山外已百年。」 | 点击产量 +15%，突破成功率 +3% |

### 7.3 数值细节
- 弟子成长：境界进度跟随掌门（掌门境界 index × 弟子成熟度%），投喂丹药加速（劣0.5%/凡1%/灵2%/珍4%/仙8% 成熟度）。
- 代际数记录 `s.generation`（第几代掌门），碑林/图鉴联动记名。
- 加成全部挂在 NEW_STATE 开局（与转生 fresh 合并）。
- 工作量集中点：弟子成长 tick、传承面板 UI、转正四选一弹窗。
