# 《灵山掌门》设定调研清单 v1（2026-09-06）

调研对象：评分最高的两部修仙经典——《凡人修仙传》（忘语，各榜第一）、《仙逆》（耳根，第二）。
配套手法参考：pelican-bike.html（SVG 角色 + IK 反向运动学动画）。

## 一、《凡人修仙传》可移植设定

| 设定 | 原作内容 | 游戏落点 |
|---|---|---|
| **法宝十一层次** | 法器(上中下品)→符宝→法宝残片→法宝→本命法宝→古宝→仿通天灵宝→通天灵宝→玄天系 | 武器图鉴的品阶骨架：法器(凡)→法宝(灵)→古宝(珍)→通天灵宝(仙)；每件武器可标注更细的层次后缀 |
| **本命法宝认主** | 法宝与元神融合、人宝同修、本命随境界成长 | 武器养成的"认主"机制：使用中武器随主人境界自动+属性，图鉴里标记「本命」 |
| **符宝（封印威能的一次性符箓）** | 结丹修士把法宝威能封入符箓留给后人 | 一次性强大道具的原型（对应现有符宝类消耗品），有出处有逻辑 |
| **灵根四类** | 天灵根(单)>异灵根(雷冰风变异)>真灵根(两三行)>伪灵根(混杂废柴，韩立即是) | 开局灵根随机（影响功法修炼速度与五行亲和）；转生/洗髓可改；伪灵根自带隐藏优势（呼应韩立） |
| **境界不符不可服丹** | 培婴丹非元婴不可服；绛云丹药性霸道境界不符有隐患 | 丹药服用境界限制：低于/高于建议境界时药效打折或丹毒加倍（与丹毒体系咬合） |
| **药效递减与依赖** | 长期依赖丹药提升修为伤根基 | 丹毒系统的设定背书（已实现） |
| **通宝诀** | 通天灵宝必须修配套功法才能驱动 | 武器+功法绑定：仙品武器需要对应功法才能真正发挥（构筑深度） |
| **正道七派+魔道六宗** | 掩月宗/黄枫谷/灵兽山/巨剑门…vs 合欢宗/鬼灵门… | 名片与好友的「门派」字段：同门切磋/敌对斗法的剧情文案差异 |
| **越国七派名** | 黄枫谷、掩月宗、灵兽山、巨剑门、清虚门、化刀坞、天阙堡 | 游戏内门派名池（好友影子随机门派，斗法台词引用） |

## 二、《仙逆》可移植设定

| 设定 | 原作内容 | 游戏落点 |
|---|---|---|
| **凝气十五层** | 凝气期内分十五小层，吞吐灵力改变体质 | 境界内「小层进度」：每个大境界分 3~5 小层，进度条刻度更有节奏感 |
| **天逆珠（时间 10:1 至宝）** | 珠内时间比外界快十倍 | 「时间加速洞天」类至宝：拥有后游戏历法流速翻倍（挂机收益同步）——稀有收集品 |
| **记名弟子/杂役起步** | 资质平庸靠毅力被破格收录 | 与游戏开局叙事一致（呼应） |
| **四步大境界** | 第一步(凝气~问鼎)→涅槃→空之四境→踏天 | 转生世界的命名：每 N 次转生后世界线进阶（远期） |
| **心性叙事** | 资质平庸靠坚韧逆袭 | 道心系统的设定背书（已实现） |

## 三、pelican-bike 手法移植清单

| 手法 | 原作做法 | 游戏应用 |
|---|---|---|
| **IK 反向运动学** | 两连杆解算膝盖，脚端沿曲柄圆轨迹踩踏 | **太极小人 v2**：双手端点沿「云手圆环」轨迹运动，肘部 IK 解算——真打太极而非摆动 |
| **部件分层遮挡** | 远侧腿画在底层被身体遮挡、近侧在上 | 小人加「远侧手臂」半透明后层，立体感 |
| **视差滚动** | 远景 7.5s/近景 4s 双层无缝循环（use href 复制） | 山影背景远近两层异速漂移 |
| **随机眨眼** | 随机间隔 scaleY 眼睑 | 小人随机小动作（眨眼/拂袖） |
| **stroke-dashoffset 流动** | 路面虚线位移 | 进度条/符文线的流动感 |

## 四、实施顺序（拍板后执行）

1. **太极小人 v2（IK 云手）**——pelican 手法直接落地，视觉冲击最大（~2h）
2. **图鉴三册**（武器/功法/丹药进见闻录）——框架 + 首批条目（~3h）
3. **武器/功法系统**（五行克制+坊市/炼器获取，坊市炼器为主奇遇为辅）+ 斗法 QTE 拔河 + 好友码影子（~10h）
4. **灵根开局 + 凝气小层**（结合转生）+ 丹药境界匹配（~3h）
5. 门禁回归 + 本地验收 → 攒批上线
