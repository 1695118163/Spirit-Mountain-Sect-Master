# 《灵山掌门》美工视觉听觉深化提案（美术 agent 出品，2026-09-05，仅方案未实施）

**公共纪律**：持续性动效优先走 CSS transform/opacity（合成器线程）；唯一新增 rAF 只在"事件期间"运行，播完即停；全局响应 prefers-reduced-motion、visibilitychange（切后台暂停）；装饰层 Canvas DPR 锁 1；新动效默认"低频、低透明度、低饱和"——纸上偶然一点墨，不是满屏特效。

---

## 一、山色四时
**概念**：山影随游戏历法四季与现实昼夜变色，世界不再是一张定格的纸。
**观感**：游戏月份映射四季——春雨后微青、夏浓黛欲滴、秋罩薄赭、冬褪灰白；入夜山影沉入黛蓝，天顶浮极淡一轮月；黄昏山脚横一条朱砂残照。纸色不动，只在山影区域罩 8%–15% 色。
**实现**：山影 Canvas 上叠两层绝对定位 div 色调层，JS 在月份/时钟变更时改 CSS 变量交叉淡入淡出（2s）；月亮用 radial-gradient 伪元素；零 Canvas 重绘、零 rAF。
**工作量**：2.5 小时
**风险**：色调只罩背景画布范围，不引入混合模式。

## 二、云生岫壑
**概念**：山腰生流云、谷底起雾带，静山之后有慢山。
**观感**：两三条半透明雾带横缠山腰，极慢相向漂移（一条 120 秒一循环），速度差造纵深。
**实现**：种子随机叠 6–10 个 radialGradient 墨团成两条云带烘到离屏 Canvas，条带比视口宽一倍，CSS transform translateX 无限循环（0→-50%），纯合成器动画。
**工作量**：3 小时
**风险**：条带高度限 300px 内，切后台暂停 animation。

## 三、风霜雨雪
**概念**：天气只作为"现象"降临，不做任何系统提示。
**观感**：以游戏日随机起天气：落雨细短墨线斜织、远山蒙水翳；落雪疏疏几点缓坠、山头渐白；起雾背景对比度整体降。见闻里补一句"是夜，雨。"
**实现**：天气机率挂在主循环日期翻转处（seed 可复现）；独立小 Canvas 专用 rAF，15fps 节流，粒子 ≤120，天气结束立即停。
**工作量**：3.5 小时
**风险**：唯一真正的常驻动画——15fps 上限+切后台杀循环+reduced-motion 禁用，三者缺一不可。

## 四、鹤唳青霄
**概念**：偶尔一只鹤横过天际，三五分钟一遇，遇上方知山是活的。
**观感**：一只 30–40px 墨鹤以"之"字形掠过山顶，约 8 秒横穿，两道弧线缓慢扇翅，淡入淡出皆无声。绝不结群。
**实现**：预生成 6 帧翅膀姿态存 Path2D 数组循环播放；复用环境 Canvas 与 rAF 预算；触发计时放 250ms 主循环。
**工作量**：2.5 小时
**风险**：频率是命门——默认 3–8 分钟一次，与天气层共享画布。

## 五、五城十二楼
**概念**：十二座建筑各得一枚"两三笔"的水墨小图标（典出昆仑五城十二楼）。
**观感**：每张建筑卡左上一方 48px 印章式小画：山门两峰夹门洞、丹房三足鼎飘烟、藏经阁叠函压庑殿顶、剑冢一竖剑配残石……每枚墨色三两笔，点一粒朱砂作睛。
**实现**：手绘 12 组 inline SVG path（每组 3–6 笔），symbol/use 复用；全局低强度 feTurbulence displacement 滤镜做枯笔毛边；悬停只动 transform。
**工作量**：4 小时
**风险**：严禁对滤镜本身做动画；图标小而钝，不抢文字主体。

## 六、一纸志怪
**概念**：奇遇弹窗顶部配一幅程序化水墨小景，同一段见闻永远长同一幅画。
**观感**：160×100 画面，主体（井、狐、剑、雨、松、舟、灯、门）偏居左下三分之一，大面积留白，右下角钤 12px 朱砂小印（取池名一字）——像志怪刻本的插图。61 条事件靠 8–10 个母题复用。
**实现**：弹窗打开时 160×100 Canvas 一次性画完（静态位图）；母题各是 3–8 笔贝塞尔函数，seed 取事件 id 复现；映射表兜底"远山+云"。
**工作量**：4 小时
**风险**：母题数量是无底洞——硬顶 8 个，宁抽象不写实；绝不做逐帧动画。

## 七、心镜无尘
**概念**：道心不再只是数字，是一枚会脏、会裂、会澄澈的圆相。
**观感**：道心旁悬一枚禅画圆相：澄明时一笔呵成的干净墨环；低落时边缘溃散、晕出淡墨渍、缺口变大、微倾；走火入魔时圆相裂作三片漂离，恢复后缓缓合拢。数字保留，圆相只作其影。
**实现**：预渲染 5 个损毁等级圆相到离屏 Canvas 作精灵，按档位交叉淡切；日常仅 CSS 8 秒呼吸缩放；碎裂=三份 clip-path 裁片+transform 过渡。
**工作量**：3.5 小时
**风险**：纯装饰，不用颜色渐变"仪表盘化"；只用 5 张静态精灵，不做墨水物理模拟。

## 八、弦外之音
**概念**：一把合成古琴自弹自听，有弹有歇，留白即是乐曲。
**观感（听觉）**：默认静音，顶栏"音"字开关。D 宫五声音阶（D E F# A B）跨两个八度，每 2–9 秒拨一音，其间常有 20–40 秒彻底安静；偶来一双五度音；约九十秒进一声箫的长音托底。突破时叠一句固定上行三音；走火入魔转羽调式，音距拉长、气息下沉。
**实现**：琴声=双振荡器（三角+正弦微失谐）+4ms 起音、1.8s 指数衰减、1.2kHz 低通，起始叠噪声"走手音"；箫=正弦加微锯齿、0.8s 慢起音；空间感用 0.28s 反馈延迟线代替混响；调度器 setInterval 500ms 向前排 1.5s 时间轴，同发音体并发≤4。
**工作量**：4 小时
**风险**：纯节点图 CPU 可忽略；切后台即静、开关默认关、音量宁轻勿吵。

## 九、檐雨虫鸣
**概念**：比音乐更低一层的"环境底噪"，让季节与天气有声音的影子。
**观感（听觉）**：极低频布料风声（0.03Hz 缓波）；入夜夏日断续虫鸣（4–5kHz 短促颗粒三连音，间隔 8–20 秒）；雨天才有的檐滴（800→300Hz 水珠声）；深夜偶有一声更漏。摘掉耳机等于没有。
**实现**：2 秒生成噪声 Buffer 循环，分叉接不同滤波链（低通=风、带通=虫、短正弦包络=滴），增益由主循环按季节/天气/昼夜推。
**工作量**：3 小时
**风险**：与提案八共用电平总线，环境层压在 -26dB 以下；同一总开关控制。

## 十、卷轴初展
**概念**：奇遇弹窗不再"弹出"，而是当着你的面展开一卷。
**观感**：弹窗化作一横卷：上下深色轴杆，纸心自中缝向上下徐徐展开约 400ms，题名最后落定墨色加深一分；仙级事件先有一道朱线横扫卷面再展卷。全程不到半秒，伴一记极短纸声。
**实现**：卷心 clip-path: inset(48% 0) → inset(0 0) 过渡；轴杆 ::before/::after 拟圆柱；题名延迟 150ms 过渡；纸声=90ms 带通噪声包络。
**工作量**：2.5 小时
**风险**：全游戏触发最频繁的仪式——总时长锁死 500ms 内，reduced-motion 退化普通淡入。

## 十一、一笔通玄
**概念**：破境过场的墨渍之上，添一笔当空写就的大字，末了一记朱印落款。
**观感**：墨渍扩散时一行草书大字凌空写出——小境界写"破"、渡劫写"渡"、化神写"化"、登仙写"仙"——小境界用墨、大境界用朱砂，约 600ms 写完，朱印带 2px 过冲"咚"地钤下，钟鸣里垫一声低沉鼓点。整段不超 1.5 秒。
**实现**：4 个大字各手绘 ≤2 笔 SVG path，pathLength=100 后 stroke-dashoffset 逐笔写出行（错峰 150ms）；朱印=方框 div scale(1.4→1)+rotate(-4°)；鼓点=120→45Hz 正弦下扫 0.4s 衰减。
**工作量**：3.5 小时
**风险**：手写行草审美下限难保——只做 4 字、只取简笔骨架、宁拙毋巧；超 1.5 秒宁可砍字。

## 十二、白纸重开
**概念**：转生不是弹窗结算，是整卷画被收走，铺开一张新纸。
**观感**：转生时界面诸元素淡去，山影褪成纯白纸——停整整两秒空屏，纸心只有一句小字（"魂归灵山，再修一世"等轮换）；随后新山自纸底向上如湿墨般晕开成形，新纪年最后浮现。燃尽的旧世界，不配任何烟火。
**实现**：走现有过场机制分四幕；新山换新 seed 画到离屏，自下而上 clip-path 展示+一次性 feTurbulence 位移模拟洇墨；空屏期 20–30 粒纸屑灰烬用一次性 3 秒 rAF。
**工作量**：4 小时
**风险**：情绪顶点最忌加料——不加金光烟花音效轰鸣；第二次起允许点击跳过。

# TOP3 推荐

**1. 五城十二楼（建筑图标，4h）**——观感收益最大：十二张建筑卡从"三行文字"变成"一图一印一名"，左栏瞬间从设置菜单变成一卷仙山楼阁图；纯静态 SVG，性能风险约等于零。

**2. 山色四时（2.5h）**——性价比之王：两个叠色 div 加几组 CSS 变量，让世界拥有时间——挂机半小时回来山色变了，正是放置游戏最想要的"世界在我离开时仍在运转"；零 rAF 零重绘。

**3. 弦外之音（生成式 BGM，4h）**——放置游戏的生命在"长待机"，听觉是长待机里唯一的持续维度——补上一床若有若无的琴箫，气质从"网页 demo"跨到"作品"；功夫花在音阶与留白的口味调校。

**备选**：若目标是把"每一次交互"做得更贵而非"让世界更活"，用《卷轴初展》（2.5h，全游戏最高频触点）替换第三个。三案合计 10.5 小时，覆盖视（山色）、物（图标）、听（琴声）三个感官。
